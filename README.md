# Juan Monsalve Career Canvas

Crea la página web estática de marca personal y portafolio profesional para Juan Monsalve (estudiante de Ingeniería Informática con proyección a desarrollo de software) siguiendo todas las especificaciones del archivo adjunto: estructura en React y Vite, estética dark mode tecnológico (fondo oscuro con superficies sutiles y acentos en rojo), tipografía (Space Grotesk para títulos, Inter para textos, JetBrains Mono para código/detalles técnicos), iconos Lucide React, 100% estático sin backend ni dependencias externas, con datos locales modulares y editable, optimizado para despliegue en GitHub Pages.

Incluye de forma completa y pulida todas las secciones:
1. Inicio / Hero: foto personal, Juan Monsalve, Estudiante de Ingeniería Informática, descripción, intereses, botones CTA y microdetalles visuales de código/terminal.
2. Sobre mí: presentación en primera persona, enfoque en desarrollo de software y aprendizaje continuo.
3. Valores: 3 tarjetas independientes para Funcionales, Sociales y Emocionales.
4. Misión y Visión: 2 tarjetas claramente diferenciadas.
5. Matriz DOFA: 4 cuadrantes visuales (Fortalezas, Oportunidades, Debilidades, Amenazas).
6. Propuesta de valor: diferenciación, resolución de problemas y valor técnico.
7. Reputación actual: 5 tarjetas de testimonios con espacios editables claramente señalados.
8. Público objetivo: Reclutadores tech y Emprendedores (perfil demográfico, psicográfico, necesidades y aporte).
9. Identidad visual: Monograma JM, eslogan "Ideas que se convierten en soluciones", paleta de colores y tipografía explicadas.
10. Estrategia de comunicación: GitHub, Portafolio web, Comunidades tech, Twitch/transmisiones y Contacto profesional con objetivos y frecuencia.
11. Hoja de vida: visualizador preparado y botones para abrir y descargar PDF.
12. Mapa de sueños: tablero de inspiración / collage de metas profesionales y personales.
13. Navegación sticky responsive con desplazamiento suave e indicador de sección activa.
